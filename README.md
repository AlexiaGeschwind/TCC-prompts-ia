# Trabalho de Conclusão de Curso (TCC) - Comparativo de Prompts de IA

Este repositório reúne os códigos de landing pages desenvolvidos e avaliados durante o Trabalho de Conclusão de Curso (TCC). O objetivo do estudo é comparar o desempenho de diferentes modelos de Linguagem (LLMs) na geração de interfaces web baseadas em três níveis/variações de prompts.

## 📁 Estrutura do Repositório

O projeto está dividido em 3 pastas principais, cada uma correspondendo a um modelo avaliado:

```text
.
├── PROMPTS CLAUDE/
│   ├── PROMPT 1/     # Interface gerada com Prompt 1
│   ├── PROMPT 2/     # Interface gerada com Prompt 2
│   └── PROMPT 3/     # Interface gerada com Prompt 3
│
├── PROMPTS GEMINI/
│   ├── PROMPT 1/     # Interface gerada com Prompt 1
│   ├── PROMPT 2/     # Interface gerada com Prompt 2
│   └── PROMPT 3/     # Interface gerada com Prompt 3
│
└── PROMPTS GPT-OSS/
    ├── PROMPT 1/     # Interface gerada com Prompt 1
    ├── PROMPT 2/     # Interface gerada com Prompt 2
    └── PROMPT 3/     # Interface gerada com Prompt 3
```

---

## 🤖 Modelos Avaliados

1. **Claude**: Testes de geração de código front-end utilizando modelos da família Anthropic Claude.
2. **Gemini**: Testes de geração utilizando modelos da família Google Gemini.
3. **GPT-OSS**: Testes utilizando o modelo GPT-OSS.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização Vanilla e Responsiva)
- **JavaScript** (Interatividade e Lógica de Interface)

## 🚀 Como Executar Localmente

Como as landing pages foram desenvolvidas utilizando HTML, CSS e JS nativos:

1. Clone este repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   ```
2. Navegue até a pasta da landing page desejada (exemplo: `PROMPTS CLAUDE/PROMPT 1`).
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
